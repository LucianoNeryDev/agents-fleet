# Roadmap

This roadmap is intentionally broad; the project is pre-release and APIs may
change.

Future plans:
 - implement session-scoped fleet selection, so each session can use a different fleet at the same time
 - tui for fleet/line modification, creation, deletion, visualization, etc (can be as a separated tool or integrate in opencode2 if possible)

## Phase 1 — Bootstrap

- Human-editable fleet and shared line configuration
- Safe validation, activation state, CLI, and OpenCode V2 integration
- Generic examples and public documentation

## Phase 2 — Hardening

- Broader OpenCode V2 compatibility testing
- More diagnostics and configuration authoring guidance
- Feedback-driven schema and migration improvements

## Phase 3 — Ecosystem

- Additional optional integrations that preserve the static-superset model
- Published release process, only after the pre-release API stabilizes
